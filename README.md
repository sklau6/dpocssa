# T26 — Centralised AI & Data Analytics Platforms

A self-contained role brief for **T26, Contract Systems Analyst (CSSA)**, covering the two centralised
platforms in scope — Chatbot-as-a-Service and the Social Media Text Analytics System — plus the duties,
requirements, operating model and measurement approach described in the position description.

## Open it

No build step, no dependencies, no network access required.

- Double-click `index.html`, **or**
- Serve the folder: `python -m http.server 8080` then visit <http://127.0.0.1:8080>

## What's inside

| Section | Contents |
|---|---|
| Overview | Role summary, at-a-glance panel, the three outcomes the role is judged on |
| Platforms | Capability lists and operating targets for both platforms, plus the five-stage adoption path |
| Scope | The seven duties from the brief regrouped into six operating pillars, with the after-hours callout |
| Requirements | The six behavioural requirements with evidence prompts, the four experience bands, and a browser-side self-check |
| Operations | L1/L2/L3 support tiers, severity-based service levels, and the operating cadence |
| Coordination | Who does what across internal teams, contractors, consultants and B/Ds, with a RACI view |
| Governance | Security, access, records, vendor control, model assurance and continuity, plus an operational checklist |
| Metrics | Six indicators with illustrative targets, adoption distribution and an effort mix |
| Roadmap | Quarterly research themes mapped to platform work, and a short market-watch list |
| Apply | FAQ and closing call to action |

## Notes on content

- Experience bands (3+ years × 4) reproduce the stated minimums exactly.
- Performance figures, service levels and the adoption distribution are illustrative design targets used to
  show how the role would be measured — they are not published commitments or system records.
- The RACI split is a working model for the role, not a delegation of authority.

## Features

- Dark and light themes, following the OS by default, with an explicit toggle remembered per browser
- Fully responsive down to 360 px; tables scroll horizontally rather than breaking the layout
- Keyboard accessible: skip link, visible focus rings, native disclosure widgets, `aria-live` self-check status
- Respects `prefers-reduced-motion`; a print stylesheet produces a clean paper brief (all FAQs expanded)
- Works entirely offline — no fonts, scripts or images are fetched from third parties
